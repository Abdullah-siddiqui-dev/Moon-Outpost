# 🌕 Moon Outpost: Junior Astronaut Mission Trainer

An interactive browser-based lunar survival and resource management game built for the **2026 NASA Space Apps Challenge**.

### 🎮 Play Live
👉 **[Launch Moon Outpost](https://abdullah-siddiqui-dev.github.io/Moon-Outpost/)**

---

### 🚀 About the Mission
Step into the role of a Junior Astronaut managing a lunar outpost. Balance critical survival systems—including **Power**, **Air**, **Shields**, and **Science**—to keep the base operational under extreme lunar conditions.

### 🛠️ Tech Stack & Workflow
* **Frontend:** HTML5, CSS3, Vanilla JavaScript
* **Development Approach:** AI-assisted rapid prototyping (Vibe Coding)
* **Hosting:** GitHub Pages
